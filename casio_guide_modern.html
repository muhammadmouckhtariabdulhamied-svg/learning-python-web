0. Turn it on and off

00

The first thing to learn is the power cycle. On the fx-991ES PLUS, the calculator turns on with the ON key.

To turn it off, press SHIFT + AC. This is the standard Casio shutdown shortcut.

Power on: ON Power off: SHIFT + AC Clear screen: AC

If the screen is blank, check the battery or make sure the calculator is not off. The calculator does not have a separate power button in the usual laptop style.

Beginner

1. Understand the three colors

01

The biggest mistake new users make is thinking every label is the same. On the fx-991ES PLUS, the same key can do up to 3 jobs.

White = normal function. Gold = press SHIFT first. Red = press ALPHA first.

Example: tan key Normal: tan SHIFT + tan = tan⁻¹

That is why the calculator looks complicated at first. The good news is that the system is consistent.

Beginner

2. Start with normal arithmetic

02

Type numbers and operations exactly the way you write them.

2 + 3 × 4 = 14 (2 + 3) × 4 = 20

Use brackets to control the order of operations. Without brackets, the calculator follows BODMAS/PEMDAS rules.

Beginner

3. Set the correct mode

03

Press MODE and choose 1 COMP for normal calculations.

Use SHIFT + MODE for SETUP, where you control things like full display formatting and angle unit.

SETUP → Deg This makes trigonometry use degrees.

If sin(30) does not return 0.5, the angle mode is probably wrong.

Beginner

4. Use Ans and replay

04

Ans stores your last answer. This saves time for chained calculations.

12 × 5 = 60 Then press ÷ 4 = Result: 15

You can also press the up arrow to revisit previous calculations and edit them without retyping the whole problem.

Beginner

5. Powers, roots and reciprocals

05

x² squares a number. x³ cubes a value. x⁻¹ gives the reciprocal.

4 x⁻¹ = 0.25 2 x² = 4 √16 = 4

Roots are extremely useful in algebra and physics. Learn the exact key pattern instead of guessing.

Beginner

6. Fractions and decimal conversion

06

Use the fraction key to enter numbers in textbook style. With one tap, you can convert between fraction and decimal.

1 a b/c 3 = 1/3 S⇔D toggles decimal form

This is one of the most useful features for school-level math.

Intermediate

7. Trigonometry: sin, cos, tan

07

You must set the angle mode first. For most school work, choose Deg.

sin(30) = 0.5 cos(60) = 0.5 tan(45) = 1

Use SHIFT + sin for sin⁻¹, SHIFT + cos for cos⁻¹, and SHIFT + tan for tan⁻¹.

Intermediate

8. Logarithms and exponentials

08

log is base-10 log. ln is natural log.

log(1000) = 3 ln(e) = 1 SHIFT + log = 10^x SHIFT + ln = e^x

These functions are essential in algebra, science, and growth/decay problems.

Intermediate

9. Scientific notation and ENG mode

09

Use ×10ˣ for scientific notation. This is perfect for very small or very large values.

3.2 × 10^5 = 320000 1.5 × 10^-5 = 0.000015

ENG mode makes the exponent a multiple of 3, which is helpful in engineering and electronics.

Intermediate

10. Memory: STO and RCL

10

The calculator stores numbers in memory variables like A, B, C, X, Y and M. This lets you reuse values in long calculations.

SHIFT + RCL = STO RCL then A recalls the stored value

Store important values when working on problems where the same input must be reused many times.

Intermediate

11. CALC mode for repeated formulas

11

CALC is a powerful tool for formulas with variables. Type the formula, press CALC, then enter each variable one by one.

A = πr² Type formula, press CALC, enter r = 5

This is excellent for checking many different values without retyping the equation every time.

Advanced

12. SOLVE and equations

12

SOLVE helps find a numerical root when you have an equation with one unknown.

x² − 5x + 6 = 0 Use SOLVE with an initial guess

It is extremely useful in applied math, physics, and engineering, especially when an equation cannot be solved by hand quickly.

Advanced

13. Complex numbers and matrices

13

The fx-991ES PLUS has strong support for complex numbers and matrix-style operations. These features are useful for advanced algebra and certain engineering tasks.

MODE → CMPLX Use complex calculations in a specialized mode

These modes are not needed daily by everyone, but they matter once you move beyond basic algebra.

Full guide: how to think about the calculator

The calculator is not random. It follows a simple rule: the key displays a normal function, then SHIFT changes it to a gold function, and ALPHA adds a red custom function.

For beginners: learn ON, OFF, AC, DEL, MODE, SHIFT, and the basic arithmetic keys first. If you can master those, the rest becomes easier.

For intermediate students: focus on trigonometry, logarithms, scientific notation, memory, and repeated formulas. These are the skills most often used in class and exams.

For advanced use: use SOLVE, CALC, memory variables, and specialized modes. These are for deeper problem solving and real-world technical work.

  • Power on with ON. Power off with SHIFT + AC.
  • Always start by checking the angle mode.
  • Use brackets whenever you are unsure about the order of operations.
  • Memorize SHIFT + function patterns instead of trying random buttons.
  • Practice with small examples before using the calculator on exam problems.
